# 短剧广场 · DRAMA HUB

DIAN115 可信扩展 v3，宿主 API **3.9+**；插件 ID `local.drama-hub`。

红果式 18 分类聚合中文竖屏短剧与漫剧：真实海报、自动追新订阅、多站点并行的防风控 PT 检索、只下 free / 2xfree 的免费种策略。

## 安装

源码目录直接包含 `plugin.json`。打包后在 DIAN115「插件中心」上传 `.dian115p`，核对安装报告后安装并启用。

更新走 inspect → update，插件 ID 必须一致，宿主会先停止活跃任务和目录轮询，**保留原有数据**。

## 能做什么

- **18 个分类频道**：精选、漫剧、闪婚、甜宠、赘婿、逆袭、古装、豪门、复仇、萌宝、战神、神医、校园、职场、悬疑、年代、穿书、玄幻。真实海报按频道并发抓取，去重后按评分与年份排序。
- **漫剧频道**：TMDB 没有「漫剧」品类，走关键词组合（动态漫 / 动态漫画 / 漫剧 / AI漫剧）叠加标题特征词强过滤，年份放宽到 2021。漫剧标题后缀（`动态漫`、`AI漫剧版`）在 PT 检索前自动剥离。
- **自动追新**：只下新集，全集下完即停。集数从标题解析（`全80集`、`第12集`、`更新至24集`、`S01E08`）。
- **多站点并行检索**：每个站独立节奏 + 随机抖动，单站绝不并发；一部订阅先问命中率最高的站，没搜到才流转下一个。
- **时间预算 + 断点续跑**：预算用完自动存档，下次从断点继续。订阅再多也不会「只查前几部」。
- **只下免费种**：`free` / `2xfree` / `free2x`，或下载系数为 0。
- **下载器手动指定**：选定后固定使用；错误翻译成人话（Cookie 失效、下载器未识别、结果不确定）。
- **Telegram 速递**：有下载或手动运行时推送。

## 站点与风控

间隔**按站点独立**计算并叠加随机抖动——固定节奏本身就是机器特征。每站有独立冷却、每日上限与连续失败退避（3 次失败当次停用，指数退避）。

命中率用贝叶斯平滑记录（`(hit+0.6)/(ok+1.2)`），好用的站先问；连续没新集自动拉长该剧间隔（最多 ×3），把额度留给正在更新的剧。

## 运行边界

插件只调用宿主已有的 PT 检索、下载器与通知接口，不读取 Cookie / CookieCloud，不向第三方上报任何信息，凭据不落在插件代码里。

PT 站点 Cookie 失效时宿主会拿回 HTML 登录页，插件把它翻译成「请到 PT 设置里重新填写 Cookie」，而不是抛原始报错。

## 目录

```
plugin.json
jobs/
  actions.js   下载器解析、错误翻译、手动操作
  digest.js    Telegram 速递
  subs.js      订阅巡检：多站并行调度、集数解析、断点续跑
  sync.js      频道同步
ui/
  page.js      页面：频道、详情抽屉、订阅列表、设置面板
  icon.svg
```

## 开发

```sh
node --check jobs/subs.js
node --check ui/page.js
node conformance/project-check.mjs .
```

`node --check` 拦不住对象字面量缺逗号这类错误（Sobek 运行时才炸），**以真机挂载为准**。
